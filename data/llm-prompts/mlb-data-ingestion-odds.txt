Convert odds and betting lines to JSON numbers, removing a leading `+` and preserving negative signs. Use null for absent or unreadable values and do not guess. Add warnings for unreadable odds, uncertain start times, or unreliable team abbreviations. Set confidence values to reflect the clarity of the extraction.

Ensure the result uses the fields and JSON structure listed above. Use valid JSON numbers and no trailing commas.
