Return JSON only. Do not include Markdown, explanations, comments, or additional text outside the JSON object.

Extraction Rules
Extract the date displayed at the top of the screenshot and convert it to ISO format:

September 29, 2026 → "2026-09-29".
Preserve the order of games shown in the screenshot.

The team listed first is the away_team; the team listed second is the home_team.

Extract the following fields for each team:

name: Full team name as displayed.
record: Overall season record, such as "88-74".
split_record: Record with the location label included, such as "45-36 Away" or "52-29 Home".
runs: Value in the R column.
hits: Value in the H column.
errors: Value in the E column.
Convert runs, hits, errors, series game numbers, and confidence values to JSON numbers, not strings.

Extract the game status exactly when possible, such as:

"Final"
"In Progress"
"Scheduled"
"Postponed"
If a postseason series line appears, extract:

league: For example, "NLWC" or "ALWC".
game: The game number as a number.
summary: The complete series summary, such as "ATL leads series 1-0".
If no series information is visible, set "series" to null.

Add a top-level "warnings" array:

Use [] when the screenshot is clear and no extraction issues exist.
Add descriptive warning strings for issues such as unreadable text, ambiguous team names, missing values, or partially visible games.
Add a top-level "confidence" object:

"overall" must be a number between 0 and 1, representing confidence in the complete extraction.
"fields" must include confidence values between 0 and 1 for:
"start_time"
"pitchers"
"odds"
"series_id"
Set confidence to 0 when a field is not visible or cannot be determined.
Set confidence to 1 only when the field is clearly visible and unambiguous.
Since the provided scorecard format does not display start time, pitchers, odds, or a series ID, use 0 for those fields unless they are visible elsewhere in the screenshot.
Add a top-level "agent_metadata" object containing:

"migrated_from_legacy_schema": Set to true when converting the result into this expanded schema. Set to false only when the source already uses this schema.
If a value cannot be read or is not present, use null. Do not guess or invent values.

Ensure all JSON is syntactically valid:

Use double quotes around keys and string values.
Do not include trailing commas.
Do not include comments.
Do not wrap the response in a Markdown code block.
Validation Checklist
Before returning the response, verify that:

The output contains one top-level "date" field.
The output contains a "games" array.
The output contains "warnings", "confidence", and "agent_metadata".
Every game has "status", "away_team", "home_team", and "series".
Each team has "name", "record", "split_record", "runs", "hits", and "errors".
Away and home teams are assigned based on their order in the screenshot.
Numeric fields are numbers.
All confidence values are between 0 and 1.
The final response contains JSON only.
